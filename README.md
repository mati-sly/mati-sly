### 📖 Biografía

Aprendí a usar Linux desde la terminal en un Chromebook. Llevo **4 años** en el ecosistema y actualmente utilizo **Linux Mint Debian Edition (LMDE)**. Me apasiona el *ricing*, la administración de sistemas y servidores, y la gestión de entornos como **Active Directory**. 

- 🚀 **Enfoque:** Optimizar flujos de trabajo y explorar herramientas de código abierto.
- 🎓 **Conocimientos:** Nivel intermedio en Python, HTML y CSS.
- 🔭 **Intereses:** Ciberseguridad, automatización y desarrollo de software.
